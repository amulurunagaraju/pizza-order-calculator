Pizza Order Calculator

About the Project:

A simple Python program that calculates the total price of a pizza based on its size and selected add-ons.

Features:

- Select pizza size (Small, Medium, Large).
- Add pepperoni if required.
- Choose extra cheese.
- Calculate and display the final bill.

Technologies Used

- Python

How to Run:

1. Download the "pizza_order.py" file.
2. Run it using Python.
3. Enter your choices to calculate the total bill.
